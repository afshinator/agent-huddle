## Assertion 2 — `DONE` accepted: holds, first proof

| hop | from | take |
|---|---|---|
| 1 | lead | 69.3s — dispatched `@dev1` to build and test a `shrink` module, ending "Report to @lead when done" |
| 2 | dev1 | **201.5s** — replied `@lead` |
| 3 | lead | 20.9s — `DONE`, `doneSignal: true` |

Room status went to `idle`. Two things this settles:

- **#30 is fixed**: a 201.5s turn completed. Under the old 120s ceiling this chain would have halted
  at hop 2, which is exactly what run #1 did.
- **#31 is fixed**: hop 1 carried "Report to @lead", and the queue went to dev1 only. Run #1's
  equivalent reply re-dispatched the lead and the wasted turn is what timed out.

Chain length fell from 4 hops (halted) to 3 hops (completed).

Observation: dev1's report was the literal text `@lead` with no content, and the lead closed the
chain on `DONE` anyway. Nothing validates a specialist's report before the lead signs off.

## Assertion 6 — Ctrl-C: holds

Single-agent room, `SIGINT` 6s into a turn, `HERDR_ENV=0`, stdin held open by a FIFO so the exit
code is readable (`wait` on a non-pipelined child):

```
sending SIGINT to 69258
exit=0
```

`state.json` afterwards: room `active`, agent `exited`; the in-flight turn's settle rejected as
`pi process for lead exited before settling`. So #27's `createShutdown` order holds against a real
signal: agents closed, flush, exit 0.

Reproduces **#34** live: the room is left `active` after a clean shutdown.

## Assertion 7 — killed child: holds

Killed the `pi` child of a lead mid-turn (the turn was doing `sleep 30` through bash):

- `messages.jsonl` hop 1: `notice` — `agent lead: pi process for lead exited before settling`.
- `state.json`: room `halted`, agent `status: "error"`.
- `telemetry.jsonl`: `agent.turn` span status `error` with the same description.

Note: the enclosing `chain` span still reports `ok` for a halted chain, so a chain's status does not
carry its agent's failure. Cosmetic, unrecorded as an issue.

Earlier attempts killed the child *after* a fast turn had already settled: the outcome was an `error`
agent status with no notice, which is correct but proves nothing about mid-turn death.
